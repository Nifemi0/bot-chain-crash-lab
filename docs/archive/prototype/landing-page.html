How the backend works.

The planner proposes bounded attacks. Deterministic execution and invariant checks decide whether the protocol actually fails.

  1. 01 / INTAKE

    Validate + map

    Confirm BOT Chain bytecode, ABI, roles, entry points, and supported invariants.

  2. 02 / SANDBOX

    Rebuild locally

    Launch an ephemeral Anvil chain with test wallets, artificial capital, and strict cleanup.

  3. 03 / EXECUTE

    Bounded agents

    Schema-validated AI scenarios become real local transactions—never shell commands or production calls.

  4. 04 / PROVE

    Capture failure

    The invariant engine records traces, losses, state deltas, and an executed Foundry reproduction.

  5. 05 / REPLAY

    Patch + attest

    Compile the fix, replay the identical attack, verify normal users, then publish only the report hash.

  2. GET /api/simulations/{id}/events → live SSE

  5. POST /api/simulations/{id}/replay → exact rerun
  6. POST /api/simulations/{id}/passport → publish hash
