# Shared UI Components

The project is a single-file static HTML prototype. It has no separate shared component library; the navigation, hero CTAs, status rail, failure-ledger rows, contract form, and footer are implemented inline in `work/test-footage-redesign.html`. Their complete implementation is preserved in `layouts.md` and should be passed directly as the primary context file for design work.

## Inline primitives

- Pill CTA links and buttons: yellow primary and black secondary variants.
- Contract address input: paper-white field with industrial mono label.
- Status badges: yellow, red, and green square indicators.
- Mobile navigation toggle and dropdown.
